What you are looking at

Real survey data, not artwork

Every pixel here comes from a Level‑2 SPHEREx science image in NASA/IPAC's public archive. The cutouts were pulled from the nasa-irsa-spherex bucket on AWS with HTTP range reads — fetching only the few hundred kilobytes that cover each target rather than each 71 MB file — and they ship with this page so it stays quick. Values are surface brightness in MJy/sr, exactly as the pipeline produced them.

SPHEREx launched in March 2025 and surveys the whole sky every six months. It carries no filter wheel: a linear variable filter means the wavelength a pixel records depends on where the source lands on the detector. That is why each visit here reports a different wavelength.

How the frames were lined up

SPHEREx revisits a target at a different roll angle every time, so raw cutouts arrive rotated against one another. Each frame was reprojected onto one shared tangent plane — north up, east left, at the native 6.15″ pixel scale — using the full TAN‑SIP astrometric solution in the file header.

The frames therefore blink cleanly against each other: if something shifts between images, it moved on the sky rather than in the telescope.

As a check: pick a star in the deep field and the visits that happen to sample the same wavelength months apart agree to about one percent. Getting that agreement requires the reprojection, the wavelength lookup and the photometry to all be right at once.

What to look for

  1. Press play and let the frames cycle. Fixed stars stay put.
  2. Pin a reference frame, then switch to Difference. A flat grey field means nothing changed; a black‑and‑white pair of dots means something moved between the two epochs.
  3. Asteroids drift noticeably between consecutive exposures taken minutes apart. Variable stars brighten and fade over months.
  4. Click a source to see how its brightness changes with wavelength — the measurement SPHEREx was built to make.

Spectra shown here are quick‑look aperture sums for exploration, not calibrated photometry.

The data behind this

Nothing here is simulated, enhanced or redrawn. Every frame is a cutout of one real SPHEREx exposure, and the panel on each frame links straight to the file it came from in NASA's archive, so any of it can be checked against the source.

Where it comes from

NASA's SPHEREx, launched 11 March 2025, surveys the whole sky every six months. These are Level‑2 science images from the Quick Release, held by IRSA at IPAC/Caltech and mirrored in the public nasa-irsa-spherex bucket on AWS.

Visits were found with ADQL against the spherex.obscore table and resolved to archive paths through spherex.artifact. Pixel values are surface brightness in MJy/sr, exactly as the pipeline produced them — no rescaling, no stacking, no cosmetic retouching.

How each frame was made

Each Level‑2 file is 71 MB, but the science image is an uncompressed array at a known offset, so only the rows covering the target were fetched over HTTP range requests — about 1.3 MB per frame.

SPHEREx revisits a target at a different roll angle every time, so raw cutouts arrive rotated against each other and will not blink. Every frame was resampled onto one shared tangent plane, north up and east left at the native 6.15″ pixel scale, using the full TAN‑SIP astrometric solution carried in its own header.

The wavelength of each visit comes from the WCS‑WAVE grid inside the same file: SPHEREx has no filter wheel, so what a pixel records depends on where the source lands on the detector. Positions for the moving bodies come from JPL Horizons, evaluated at each exposure's own timestamp.
