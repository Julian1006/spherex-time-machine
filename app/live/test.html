sxlive self-test

Checks that a browser can read SPHEREx images straight from NASA's public bucket, with no server in between, and that what it reads matches the frames the Python build produced.

1. Same pixels as the build

A few frames that ship with the site are fetched again from the bucket and rebuilt here. Every pixel should match what the build stored, to the precision it was stored at (16-bit floats).

2. A place the site has never seen

The exposure list for each object came from one IRSA query. From there everything is live: the bucket is asked which processing version to read, then for the header and the rows of each exposure.

3. The pointing index finds what IRSA finds

For each object the index is searched in the browser and compared with IRSA's own answer for the same spot. Then the pixel the index predicts is checked against the real astrometry in the file.
